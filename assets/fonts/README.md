# Bundled fonts

Noto Sans provides Latin and Vietnamese characters. Noto Sans JP provides
Japanese fallback characters. Both are bundled so browser rendering does not
depend on fonts installed on the player's device.

Sources: [Noto Sans](https://github.com/google/fonts/tree/main/ofl/notosans)
and [Noto Sans JP](https://github.com/google/fonts/tree/main/ofl/notosansjp).
Each font's SIL Open Font License is included beside the font file.
